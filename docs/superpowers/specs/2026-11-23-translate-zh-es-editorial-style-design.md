# 中文到西班牙语翻译 skill：编辑风格优化设计

## 目标与范围

提高从完整中文文章直接产出逐段中西对照初稿的质量。以三篇已修改稿为参考，提炼可迁移的表达判断，而不保存样本句、建立逐稿学习机制，或增加 DOCX 处理和已有西语译文审校模式。

## 翻译判断

1. **按文章及段落功能调节文风。** 文旅、文化特写和叙事报道可用具体画面、自然节奏及有表现力的西语；说明性事实、人物引语和专业内容按其功能保持清楚、准确。允许小幅提高感染力，但不改变事实、立场、人物语气或事实判断的确定性，也不新增独立评价。
2. **优先译出意象的实际功能。** 文化、体育等领域的隐喻和惯用说法应转成西语读者自然理解的表达，避免逐字硬译；领域术语保持准确。不得为求文采补造事实、身份、因果或评价。
3. **区分独立古诗文材料的内容类型。** 古诗正文仅保留中文；标题、作者、题解、现代汉语释义和原文自带的出处说明按单元翻译。题解可适度有文学表现力，现代释义以清楚、准确为先。题解中的“可能”等不确定性必须保留；编辑定稿里的个别背景扩写不成为初译常规。
4. **纠正与风格无关的语言错误。** 风格样本不覆盖西语语法、搭配和标点规范。最终校对继续检查词性、性数、介词、拼写及标点。

- `skills/translate-zh-es/references/genre-style-guide.md`：补充文旅和文化特写的表达边界；区分诗文题解与现代释义。
- `skills/translate-zh-es/references/translation-principles.md`：将适度感染力、领域隐喻和事实边界写成可执行的判断规则。
- `skills/translate-zh-es/references/quality-assurance.md`：解决“独立古诗正文不译”与“每个诗节都须对译”的冲突；检查出处、判断强度、文体节奏和自然的领域用语。

## 验收

- 用不依赖样本原句的短材料检验：文旅/体育标题避免逐字硬译，叙事有画面但不夸张；引语的语气与事实准确。
- 古诗文材料中，古诗正文保留中文，题解和现代释义各按功能翻译，原文自带出处得到对应翻译，原文的不确定性不被抬高或消除。
- `SKILL.md` 与四份参考文件的规则相容，且不引入 DOCX 工作流或已有译文审校流程。

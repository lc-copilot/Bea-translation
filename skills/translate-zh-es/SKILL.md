# 中文 → 西班牙语翻译

## 适用与不适用

- 适用：中文 → 西班牙语；语料是一篇保留原始段落结构的完整中文文章；目标读者是面向西语国家的一般文化刊物读者（用户另有说明时按其说明调整）。
- 不适用：西语 → 中文翻译；DOCX/PDF/HTML 等文件格式的解析、生成、转换、回写与版式处理；OCR 或图片文字；自动化翻译质量回归测试建设。

## 工作模式

唯一的模式：把完整中文文章翻译成逐段中西对照成稿。skill 的改进通过直接对话完成，不在 skill 内部维护学习或样本积累流程。

## 核心流程

1. **阅读全文**：第一遍只理解，不翻译。识别主题与传播目的、文体与正式程度、逻辑结构、重要事实与专名、情感与评价强度、影响一致性的术语和文化词。
2. **建立本篇内部翻译基准**：形成语体、措辞正式程度、术语决策、文化解释尺度。仅供内部使用，不展示，不用固定规则替代针对文章的判断。
3. **核实专名、术语与表达**：对专名、领域术语、固定搭配和已有译法的表达主动核实，不只在明显不确定时核实。加载 `references/research-and-terminology.md`。
4. **逐段翻译**：以段落为基本单位，持续参考全文与相邻段落；允许补主语、拆长句、合短句、调序与显化逻辑连接；不得添加原文没有的独立事实或评价。加载 `references/translation-principles.md` 与 `references/genre-style-guide.md`。
5. **三遍内部质检**：忠实度检查 → 西语母语化检查 → 最终校对。加载 `references/quality-assurance.md`。
6. **输出成稿**：只交付连续的内容单元（中文原文 → 对应西语 → 必要时的注释）；独立古诗正文按下述例外处理。原文自带的出处说明照常对译，但不另附研究来源清单、翻译说明、术语表、质检报告或完成总结。长文章分批翻译时，每批携带全文基准与术语表，全部完成后重新通读整篇西语并逐段回查中文。

## 输出约束

- 中文逐字保留：不改字、不改标点、不纠错、不润色、不重排。
- 西语可在单个内容单元内拆句、合句、调整顺序，但不得跨单元合并或拆分原文。
- 独立古诗材料中的古诗正文只保留中文，不配西语；标题、作者、题解、现代汉语释义及原文自带的出处说明仍逐单元对译。
- 注释只在必要且无法自然融入译文时添加，无固定词数阈值；没有则不输出空注释或占位文本。

## 语言基准

- 自然、正式、清楚可信的泛西语书面语，以 RAE/ASALE 标准书面西语为基础。
- 避免单一国家特有的俚语和强地域词；不把广泛可理解的正常词汇机械替换为所谓中性词。
- 风格接近高质量文化刊物，不写成生硬政府公文或学术论文，不堆砌罕见词制造高级感。

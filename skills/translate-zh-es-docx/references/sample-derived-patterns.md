# 样本规律（sample-derived-patterns）

本文档记录从用户提供的真实样本中提炼的正面倾向与必须禁止的错误。用于选择出版措辞时加载。

## 证据状态

- 本文件的规律来自对样本成稿与用户反馈的归纳，属于强倾向而非绝对规则。
- 与 `translation-standard.md` 冲突时，以翻译标准为准；发现新的可靠样本时更新本文件。

## 优选习语

- 文化相关的惯用语优先译成西语中功能对等的习语，而不是字面直译。
- 中文四字格与成语：优先找到西语对应表达；没有对应时译出实际含义，不堆字。
- 数字与比喻（“万家灯火”“千里之外”）按西语表达习惯处理，保留画面感。

## 领域术语

- 体育、教育、文化、政务等领域的术语统一使用该领域的标准西语说法。
- 同一术语在同一篇内不得混用不同译法。
- 机构职位、头衔按官方译法处理；无法核实时用描述性译法并保持一致。

## 文化精准

- 物质文化词（炕、古琴、瑶琴、七弦琴、里、亩等）必须既保留原文概念又让西语读者可理解。
- 短解释（≤ five Spanish words）用括注；长解释用 true Word footnote，标记在标点后。
- 拼音形式与汉字形式不得混用造成重复冗长。

## 已核实专名

- 优先采用已核实的官方名，例如孔子学院（Instituto Confucio）。
- 无官方译名的中文人名使用无声调拼音，姓在名前（surname before given name）。
- 专名首次出现后，后续出现保持完全一致。

## 禁止错误

以下错误一旦出现即为不合格，必须在三遍质检中清除：

- 拼写与搭配错误：如 `motoroes`、`del información`、`optimización refinida` 之类的形式。
- 性数不一致、动词变位错误、前置词搭配错误。
- 把中文标点（顿号、书名号）或中文语序直接搬进西语。
- 西语中夹带未处理的汉字（文化解释括注中的汉字展示除外）。
- 对中文的漏译、跳段、或把段落合并导致配对破坏。
- 使用翻译腔句式：逐字对应但不符合西语习惯的结构。

## 反膨胀规则

- 西语译文长度允许略长于中文，但不得为凑字数或凑对称而增写内容。
- 不得添加原文没有的观点、评论或情绪渲染。
- 每一处增写（如文化解释）都必须有明确理由，并符合解释长度规则。
